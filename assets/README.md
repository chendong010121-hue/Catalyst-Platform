# Catalyst Organizational Assets

This directory contains small, governed pieces of organizational value that have earned preservation beyond the implementation or Case that originally produced them.

It is **not**:

- a Capability Registry;
- a database;
- a universal Capability schema;
- a health/status system;
- an asset graph;
- a replacement for authoritative contracts or evaluation evidence.

The rule is:

> **Preserve the smallest durable value; keep provenance; reference authority instead of copying it.**

Current navigation starts at:

```text
CATALYST_CAPABILITY_VISIBILITY_INDEX_V0.1.json
```

The Index helps a human or Harness find these assets; the asset itself owns only the bounded knowledge it explicitly claims.

## Current asset classes

```text
assets/knowledge/
```

contains mechanism/safety knowledge that is useful independently of the original Agent or Case implementation.

An asset may later be replaced, revised, composed into a Capability, or retired. Presence here does not automatically grant Platform Capability identity or Platform Core authority.

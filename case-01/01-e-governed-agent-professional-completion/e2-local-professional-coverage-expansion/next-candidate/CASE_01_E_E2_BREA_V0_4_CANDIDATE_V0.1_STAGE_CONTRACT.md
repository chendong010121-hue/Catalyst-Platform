# 4. Product behavior that v0.4 must provide

Within the current admitted local corpus, v0.4 must provide one coherent local professional-query path rather than separate benchmark-specific family routes.

Minimum supported professional forms:

```text
direct normative clause
conditional rule
condition-dependent table rule
positive scope + exception / exclusion
derived numeric modifier
```

For supported questions the Agent must be able to:

```text
1. accept natural-language regulation questions,
2. normalize project facts,
3. retrieve source evidence,
4. derive a generic semantic view from evidence,
5. determine applicability through SEAM-02 responsibility,
6. preserve source / locator / verbatim evidence,
7. return source-backed table values,
8. distinguish source numeric from derived numeric,
9. show derivation trace when calculation is performed,
10. fail closed when source, facts, applicability or numeric support is insufficient.
```

Retrieval does not equal applicability.

# 5. Mandatory v0.3 professional repairs

The next Candidate must close the known v0.3 defects as general professional contracts, not as new one-off branches.

## P-01 Positive applicability

A public-building rule may not be applied merely because no exclusion matched.
Positive applicability scope must be established.

## P-02 Material condition distinction

Materially different rule conditions must remain distinguishable.
Known example:

```text
underground equipment room
!=
other underground area
```

## P-03 SEAM-02 ownership

Professional applicability logic must remain observable through the accepted SEAM-02 responsibility.
Runner/orchestration may call it but must not become the hidden owner of applicability semantics.

## P-04 Derived numeric safety

Derived numeric output must preserve:

```text
source operand
source modifier/operator
runtime formula
runtime result
source evidence
```

Derived values must remain distinguishable from source-verbatim numerics.

## P-05 Table numeric fidelity

If the selected evidence is a table rule, the actual source-backed row/column values must be bound to the answer, not only an abstract outcome label.

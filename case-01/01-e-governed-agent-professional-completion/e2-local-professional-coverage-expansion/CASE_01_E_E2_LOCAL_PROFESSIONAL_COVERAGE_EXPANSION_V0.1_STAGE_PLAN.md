# 0. E2 Thesis

E1 proved:

```text
BREA v0.2-candidate
→ generalized deterministic local evidence retrieval
→ over the two currently admitted local regulation corpora
→ without benchmark-specific runtime hardcode
```

E2 must now answer a harder product question:

> **Can BREA expand into genuinely broader local professional coverage while preserving the generalized mechanism, professional responsibility boundaries, evidence obligations and Catalyst governance discipline?**

E2 is not a “more files” Stage.

The target is:

```text
new real professional coverage
+
new admitted local professional source(s) and/or materially new evidence type(s)
+
no regression to fixture-specific branches
+
independent professional evaluation
```

E2 is also the first Stage intentionally designed under the accepted:

```text
CATALYST_GOVERNED_AGENT_CONSTRUCTION_METHOD_V0.1
```

Therefore E2 must leave evidence that the applicable P-01 → P-09 Method chain was actually used.

# 1. What E2 Must NOT Do

E2 must not begin by saying:

```text
“add 10 more regulation files”
```

or:

```text
“add RAG / LLM because the corpus is getting larger”
```

E2 first identifies a real professional coverage gap and only then selects source / mechanism / technology.

E2 does not automatically include:

```text
Web fallback
Internet search
official-site verification
RAG
vector database
LLM
Agent loop
Memory
frontend
backend
IAM / RBAC
Enterprise policy engine
Platform Core change
Runtime change
```

Any of those requires evidence from the actual E2 problem.

# 2. Product Objective

E2 should materially increase the set of real architectural / preliminary-design regulation questions BREA can support using local authoritative evidence.

The minimum intended product improvement is one bounded professional slice that is **clearly outside the original T-C01 / T-C02 / T-C03 fixture family**.

Examples of eligible slices include, subject to real corpus evidence:

```text
fire-safety questions beyond the existing fire-distance rule

parking / access questions beyond the current allocation-table path

a third locally available building-regulation source

new clause / table forms that stress the generalized parser

professional applicability that requires additional project facts
```

The Stage must choose the slice from actual available professional evidence, not from an invented roadmap.

# Audit Workflow

Each external-audit candidate should maintain:

```text
HANDOFF.md
IMPLEMENTATION_NOTES.md
INTERNAL_AUDIT_REPORT.md
TEST_MANIFEST.md
```

GitHub Actions is independent repetition of defined tests.

DeepSeek Internal Audit is adversarial white-box review.

ChatGPT External Audit is independent architecture/recovery/contract review.

They are complementary, not substitutes.

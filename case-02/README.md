## Purpose

CASE 02 is an independent Catalyst case used to test whether the methods proven or derived in CASE 01 transfer to a meaningfully different Agent.

The goal is not to rebuild the Agent immediately.

The first objective is:

```text
SOURCE AGENT
→ blind understanding
→ evidence-backed behavior / intent recovery
→ functional decomposition
→ responsibility classification
→ asset / accidental-architecture separation
→ admission / adoption feasibility
→ only then decide whether to preserve, wrap, adapt, or build a governed successor
```

## Governing principles

- Product / Agent first; Platform promotion later.
- Understand before repairing.
- Reuse assets and evidence; do not inherit accidental architecture.
- Internal components may be decomposed and governed without becoming Platform-level resources.
- Preserve Agent identity, purpose, responsibility, evidence, version, and replaceability.
- External frameworks or implementations are references, not architecture authorities.
- Minimal artifacts only: create a new artifact only when it has independent decision value.
